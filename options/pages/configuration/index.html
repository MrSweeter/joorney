Language

Language of the texts added by Joorney: popup, options, buttons and notifications in Odoo, right-click menu and address bar suggestions.

Follows the display language of your browser.

Follows the language of the Odoo user on each database.

Always uses the language selected here, whatever the browser or Odoo language.

  • Outside Odoo pages (options, address bar, a database not opened yet): the browser language.
  • Reload any open Odoo tabs to apply the change.
  • Unsupported languages fall back to English.
  • In Chrome, the extension name and description follow the browser language.
